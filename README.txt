HOW TO USE ON WINDOWS
1. Extract this ZIP.
2. Open index.html in Chrome or Edge.
3. Admin PIN is 1234.
4. Submitted records are saved in that browser on that device.

HOW TO USE ON CELLPHONES OFFLINE
1. Copy the extracted folder to the cellphone.
2. Open index.html in Chrome.
3. Use the browser menu and select "Add to Home Screen" if available.
4. Records will work offline on that same phone.

IMPORTANT
- Offline records stay on the device where they were submitted.
- To collect records from another phone, open Admin > Export Backup JSON.
- On the admin device, use Admin > Import Backup JSON.

ONLINE QR VERSION
To make one QR code that all students scan:
1. Upload this folder to website hosting.
2. Create a QR code pointing to the hosted index.html link.
3. Students scan the QR and submit.
4. For automatic central storage across all phones, use a server/database version.
