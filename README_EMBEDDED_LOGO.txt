SAFE FLY EXPRESS PORTAL - EMBEDDED LOGO VERSION

This version embeds the uploaded Safe Fly Express logo directly into index.html.
That means there is no external logo file path to break.

Upload these to GitHub Pages:
- index.html
- app.js
- manifest.json

You do not need to upload an assets folder for the logo in this version.

After upload:
- Wait 2 to 5 minutes.
- Open the live site.
- Press Ctrl + F5 to force refresh.
